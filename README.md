🛒 Cadastro de Produtos

Sistema simples desenvolvido em PHP para cadastrar produtos e armazená-los em um banco de dados MySQL.

✨ Funcionalidades

📝 Cadastro de produtos

💰 Registro de nome e preço

✅ Validação dos dados

⚠️ Mensagens de erro e sucesso

🗄️ Armazenamento no MySQL

🛠️ Tecnologias

🐘 PHP

🌐 HTML5

🗄️ MySQL

🔗 MySQLi

🚀 Como executar

Instale um ambiente como XAMPP, WAMP ou Laragon.

Inicie o PHP e o MySQL.

Crie o banco de dados e a tabela de produtos.

Coloque o projeto na pasta do servidor.

Acesse o projeto pelo navegador.

🎯 Objetivo

Projeto desenvolvido para praticar PHP, formulários, validação de dados e integração com banco de dados MySQL.
